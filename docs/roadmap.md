# Roadmap

## Current Showcase

- Sanitized documentation.
- Synthetic sample notes.
- Dependency-free local demo.
- Localhost-only Qdrant Compose example.
- Security model and publication boundary.

## Short Term

- Add a Qdrant-backed implementation behind the same store interface.
- Add tests for exclusion rules, chunking, and deterministic search.
- Add CI that runs the demo commands.
- Add generated screenshots of search and context pack output.

## Medium Term

- Add MCP server examples for coding-agent integration.
- Add retrieval quality fixtures and regression checks.
- Add import tooling for curated Markdown folders.
- Add safer context-pack size budgeting and deduplication.

## Long Term

- Add optional semantic embedding providers.
- Add local-only web UI for inspecting indexed chunks.
- Add backup and restore examples.
- Add documentation for operating the private version without exposing data.
